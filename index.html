02 / 我们做什么

从第一行代码
到第一个作品

会多少都能找到位置：写程序、接电路、做结构、写文档、拍照片，都算参与。

01

Arduino 入门

从点亮第一颗 LED、读取按钮和传感器开始，学习数字/模拟输入输出、串口和基础程序结构。先跑通，再理解，最后试着改。

02

硬件项目实战

组队做 Arduino 小装置、传感器互动和校园硬件小工具。有人写程序，也有人做电路、结构、测试和文档。

03

程序与调试

围绕 Arduino 项目练习变量、循环、函数和状态判断，学会看串口输出、定位问题，再把思路延伸到算法与竞赛。

04

分享与协作

每周两次、每次一小时的活动里安排主题分享，把踩过的坑写成文档。代码、设计、文案全部开放，互相看代码，也互相兜底。

06 / FAQ

加入之前
你可能想知道

零基础可以加入吗？

可以。社团里有很多人也是从零开始的。你不需要先学完某门课再来，带着问题和兴趣来就够了。

社团主要教什么？

教学内容以 Arduino 为主线：从点亮 LED、读按钮和传感器开始，学习数字/模拟输入输出、串口、简单控制逻辑，再完成一个完整的硬件小项目。ESP32 会作为进阶平台接触。

需要自己带电脑吗？

有电脑会更方便，但不是硬性要求。没有电脑也可以先来听分享、参与讨论和设计，之后再决定怎么参与项目。

不是技术方向也能加入吗？

可以。一个项目除了写代码，还需要设计、文案、测试和活动组织。你可以先认领一件小事，再慢慢找到自己擅长的部分。

活动时间是什么时候？

常规活动每周两次，每次一小时：一次主题分享 + 结对开发，一次自由开发 + 问题排查。具体时间和地点会在 QQ 群公告里通知，考试周会适当调整。

项目卡片的数据从哪里来？

卡片读的是每天自动生成的一份仓库快照，不消耗你的 GitHub 额度。快照里缺某个仓库时，才会去问 GitHub 实时接口；再不行还有本地缓存和降级卡片，页面不会空白。

点右上角的圆形箭头，会跳过快照和十分钟缓存，直接向 GitHub 要一次最新数据，并把结果存在本地，打开其它页面也是新值。一次刷新只花「仓库个数」次请求；撞上限流会提示稍后再试，已有数据不会被清掉。
